# 💌 传讯 · 情侣聊天应用

一款纯前端实现的「情侣专属聊天 + 互动」网页应用，无需服务器、无需登录，双击 `index.html` 即可在浏览器里运行。所有数据保存在浏览器本地（localStorage / IndexedDB）。

## 🚀 如何运行

**方式一（最简单）**：直接双击 `index.html`，用浏览器打开即可。

**方式二（推荐，可自动记忆数据）**：本地启动一个静态服务器，避免浏览器对本地文件的限制。

```bash
# 任选其一
python -m http.server 8000
# 或
npx serve .
```

然后浏览器访问 `http://localhost:8000`。

## 🛠 技术栈

- 纯原生 HTML / CSS / JavaScript（无框架、无构建步骤）
- 数据存储：localStorage / IndexedDB（浏览器本地）
- 字体图标：Font Awesome

## 🌍 部署到 GitHub Pages

1. 把本目录上传到你的 GitHub 仓库（`<你的用户名>.github.io` 或任意仓库名）
2. 仓库 `Settings → Pages → Source` 选择 `main` 分支 / `root` 目录
3. 保存后，访问 `https://<你的用户名>.github.io/<仓库名>/` 即可在线使用

## 📝 说明

- 本应用为情侣互动娱乐用途，所有数据仅保存在打开它的浏览器本地，更换设备或清除浏览器数据后需重新填写。
